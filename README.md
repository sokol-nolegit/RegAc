Инструкция по сохранения самого первого токена:
0. Запустить приложение
1. Нажать "1" + Enter
2. В открывшемся поле, нужно ввести заметку по аккаунту, который вы сохраняете, если она не нужна, просто нажмите "Enter"
3. После этого нажмите "Enter"

Инструкция по вставке сохранённого тикета:
0. Запустить приложение
1. Нажать "3" + Enter 
2. Выбрать нужный аккаунт числом, которым он сохранён и нажать "Enter" два раза
